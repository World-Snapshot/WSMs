- **How do we define and implement an ideal world model?** Our answer is to encode world information into image-like World Snapshots. World Snapshot Graphics (`.wsg`) provides the representation, the Unified Law for Visual Tasks provides the principle, and WSM provides the executable model. Predicting the next token can lead to LLMs; encoding information onto the boundary of the world can lead to WSMs.
- **How do we achieve true multimodal fusion and storage?** Store the information in the image itself instead of attaching every modality as an external label. RGB, geometry, motion, pose, physics, material, semantics, audio, and other visualizable quantities become aligned channels of one World Snapshot.
- **How do we unify generation and understanding?** Generation and understanding become the same kind of task once both are expressed as generation toward an explicit image-like target. Estimation generates a requested World Snapshot from RGB; generation produces RGB or another snapshot from text or visual evidence.
- **Why are there Four Laws of Computer Vision?** In our experiments, nearly all visual tasks can be executed through four evidence–target interfaces: generation, estimation, conditional control, and reconstruction. These are interface forms, not artificial boundaries between research communities.
- **How are thousands of visual tasks defined?** A visual task is defined jointly by its input evidence and requested output target. Changing either side creates a different task form: for example, RGB → Depth and Normal → Depth request the same output from different evidence and are therefore different tasks. WSM organizes these evidence–target definitions systematically within one interface system.
- **How do we train thousands of tasks without duplicating thousands of models?** TunnelingNet keeps one shared visual generator and learns a compact path for each task. These paths can be optimized independently and in parallel, then registered together in the same deployed model.
- **Are Channel Heads fragmented models?** No. Separate files are convenient for training, validation, distribution, and continued improvement. At deployment they form one task-indexed bank around one backbone; selecting a task activates its route, while visual chains activate successive routes.
- **How does breadth become reasoning depth?** A generated World Snapshot can become evidence for another task. Connecting trained routes creates Chains of Visual Thought, allowing the system to construct deeper visual programs from the same graph.
- **How can visual models acquire physical and geometric reasoning?** Geometry, support, density, weight, friction, material, motion, and related quantities must first become explicit visual targets. The present release demonstrates these associations; causal dynamics and physical laws remain important directions for deeper WSMs.
- **Why can a task tunnel learn without forcing every modality into one shared internal language?** A normal-sighted observer and a red–green color-blind observer can describe the same object without sharing identical perception. Likewise, task routes can learn their targets separately while still using the same visual generator.
- **How are categorical masks handled?** The generative route predicts spatial support, while a small task-bound categorical refiner identifies and recolors the generated regions.
- **What does WSM unify?** Papers with Code recorded 1,477 visual or vision-related tasks. All 1,477 can be expressed through the WSM interfaces, showing that the framework is compatible with the established field of Computer Vision.
- **What does WSM create?** After historical overlaps are removed, an estimated 655–1,056 of the 1,148 evaluated WSM tasks are new. WSM therefore expands the established Computer-Vision task space by 44.3–71.5% while providing a trained baseline for every evaluated task.
