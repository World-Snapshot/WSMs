# Contributing

Thank you for contributing to WSMs. Once we see your message or contribution, we will try to respond within 36 hours.

If you develop a new model, you can submit it as a new directory in the repository root, for example `WSM_v1_new_model`. You are welcome to give it your own name. We can then help introduce and promote it in the README.

For regular bugs or suggestions, please submit an Issue or Pull Request and work with the authors or the community to resolve them.
